# Project Overview

This is a multi-page e-commerce website for a brand called "Earthy Munchy". The website is built with HTML, CSS, and JavaScript, using Vite as a build tool. It uses Tailwind CSS for styling, GSAP for animations, and Lucide for icons. The site has a modern design with a focus on high-quality visuals and animations.

## Features

*   **Moodboard-Driven Design**: A curated color palette featuring Sage Green, Terracotta, Cream, and Clay optimized for a natural feel.
*   **Premium Micro-interactions**:
    *   Parallax scrolling effects.
    *   Hover-triggered 3D transforms for product jars.
    *   Shimmer effects on ingredient cards.
    *   Intersection Observer-based fade-in reveals.
*   **Responsive Layout**: Fully responsive fluid design using modern CSS Grid and Flexbox.
*   **No Heavy Dependencies**: Built with vanilla HTML, CSS, and JavaScript. (Vite is included for development convenience).

## Key Technologies

*   **Vite:** A modern build tool for web development.
*   **Tailwind CSS:** A utility-first CSS framework.
*   **GSAP (GreenSock Animation Platform):** A JavaScript library for creating high-performance animations.
*   **Lucide:** A library for clean and consistent icons.
*   **Three.js:** A 3D graphics library for creating and displaying animated 3D computer graphics in a web browser.

## Project Structure

The project is a multi-page application with the following HTML files:

*   `index.html`: The home page.
*   `contact.html`: The contact page.
*   `product-cinnamon.html`: The product page for cinnamon.
*   `product-cloves.html`: The product page for cloves.
*   `product-honey.html`: The product page for honey.
*   `shop-honey.html`: The shop page for honey products.
*   `shop-spices.html`: The shop page for spice products.
*   `shop.html`: The main shop page.
*   `story.html`: The page that tells the story of the brand.

The `public` directory contains all the static assets, such as images and videos.

### JavaScript and JSON Files

*   `cart.js`: This file contains the logic for the shopping cart functionality. It uses `localStorage` to persist the cart data, and it dynamically creates the cart UI. The checkout process is handled by redirecting the user to WhatsApp with a pre-filled message containing the order details.
*   `products.json`: This file contains all the product information for the website. It has a well-defined structure, with a `brand` object, `manufacturer` and `distributor` information, `categories`, and a list of `products`. Each product has detailed information, including SKU, barcode, description, features, usage, origin, ingredients, and more. This file is likely used to dynamically generate the product pages and other product-related content on the website.
